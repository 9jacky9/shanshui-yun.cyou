山水云隐私政策与零日志安全声明

核心承诺：零用户活动日志留存（Zero Activity Logs） 存储介质：全节点 RAM-Only 内存态运行
核心隐私承诺：山水云在系统设计与日常运维中严格遵循“零用户活动日志留存（Zero User Activity Logs）”原则。我们绝不记录、不监控、不存储、也不向任何第三方出售或披露您的网络浏览历史、目标访问域名、DNS 查询请求、传输数据内容及真实源 IP 地址。

一、我们绝对不收集的数据（零日志范畴）

当您通过山水云全球任一节点进行网络通信时，所有边缘中继服务器与落地网关均运行在定制的只读内存文件系统（RAM-Only Diskless System）之上，服务器本地不挂载任何用于写入日志的持久化硬盘：

  • 不记录访问内容与目标地址：我们不知道您访问了哪些网站、调用了哪些 API 接口或观看了哪些流媒体内容。
  • 不记录源 IP 与连接时间戳：会话断开后，内存中的临时 NAT 映射表立即自动销毁，不留存任何历史连接源 IP 记录。
  • 不记录 DNS 解析历史：山水云内置的加密 DoH/DoT 递归解析器完全在内存中高速缓存，不写入任何查询流水。

二、维持基础账户运作所需的最小化信息

为了向您交付订阅配额并提供售后服务，控制面板仅保存维持账户正常运转所必需的极简元数据：

  • 注册邮箱标识符：用于登录验证、接收订阅到期提醒及工单回复（支持使用匿名邮箱注册）。
  • 周期汇总流量数值：系统仅统计账户在当前计费周期内消耗的总字节数（例如已使用 45.2 GB），用于计算剩余配额，不包含任何细化的连接明细。
  • 脱敏支付状态凭证：支付过程由第三方合规加密网关处理，山水云不存储您的银行卡号或完整支付账户私钥。

三、端到端加密与前向安全性

山水云全线传输协议均启用 TLS 1.3 与 ChaCha20-Poly1305 / AES-256-GCM 强加密算法，并强制开启完全前向保密（Perfect Forward Secrecy, PFS）。每次握手均动态生成一次性椭圆曲线密钥（ECDHE），即便在极端网络窃听环境下，历史通信数据包也无法被逆向解密。

四、用户数据控制权與账户注销

您拥有对个人账户数据的完全控制权。您可随时在用户中心申请永久注销账户，注销指令执行后，系统将立即不可逆地清除与该邮箱关联的所有订阅哈希值与工单记录。若对本隐私政策有任何疑问，欢迎浏览关于我们或服务条款获取更多说明。
