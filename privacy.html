隐私政策

1. 信息收集范围

山水云选用指南作为纯静态内容展示网站，本身不设置任何用户注册表单、登录认证系统或在线支付模块。在您浏览本站页面时，本站不会主动要求您提供姓名、手机号、家庭住址或财务账号等个人敏感信息。

2. Web 服务器常规日志

与绝大多数基于互联网运行的标准 Web 站点相同，承载本站静态文件的托管服务器或内容分发网络（CDN）会自动记录标准的 HTTP 访问日志。这些信息通常包括您的访问时间、请求的页面 URL、浏览器类型（User-Agent）以及发起请求的 IP 地址。此类数据仅用于服务器基础性能排查、防范恶意攻击与保障网站正常运转，不用于识别特定个人的真实身份。

3. Cookie 与第三方服务

本站核心页面不主动植入广告跟踪 Cookie。若本站集成了通用的无状态静态资源加速服务，相关服务商可能会在其基础设施层面使用必要的技术标识符来保障缓存分发效率。当您通过本站的链接跳转至第三方外部平台时，该第三方平台将根据其自有的隐私政策处理您的数据，本站无法干预其数据收集行为。

4. 隐私安全原则

本站高度尊重并重视访问者的隐私权益。我们承诺严格按照最少必要原则处理网络访问数据，不向任何第三方商业机构出售或非法共享服务器访问日志。
